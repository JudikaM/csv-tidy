3 Describe the columns

After a file is loaded, each column is listed here. Every column starts as plain text: CSV Tidy never guesses which columns are numbers or dates. You decide, or you load a profile that already contains the rules.

Load rules from a profile file (optional)

A profile is a small .toml file with saved rules. You can save one in step 6.

The example shows 31 December 2026 in each format. 01/02/2026 is never guessed: it is 1 February with DD/MM/YYYY and 2 January with MM/DD/YYYY.

More settings

A longer value stops reading with "field too large". It usually means an unclosed quote. Raise it only for files with very long texts. Saved in profiles as max_field_chars.

How much detail to show

Counts are always complete. These limits set how many items are listed on the page and in saved reports.

Combined unique keys

Use this when two or more columns together must be unique (for example customer and date).
