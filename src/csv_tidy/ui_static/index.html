      1 Choose the file

      • One file checks and cleans a single CSV file. Several files applies one set of column rules to every chosen file.
      • The separator is not detected automatically. If the preview in step 2 shows one wide column, switch it.
      • Change the encoding if letters such as é or ñ look wrong, or the file cannot be read.

      Chosen files

      Every file is checked and cleaned with the same separator, encoding, and rules. The rules in step 3 are based on the columns of the file you preview.

      FileSizeActions

      2 Look at the data

      The first rows of your file appear here, exactly as they are stored. Use them to confirm the separator and encoding before setting any rules.

      3 Describe the columns

      After a file is loaded, each column is listed here. Every column starts as plain text: CSV Tidy never guesses which columns are numbers or dates. You decide, or you load a profile that already contains the rules.

      Load rules from a profile file (optional)

      A profile is a small .toml file with saved rules. You can save one in step 6.

      The example shows 31 December 2026 in each format. 01/02/2026 is never guessed: it is 1 February with DD/MM/YYYY and 2 January with MM/DD/YYYY.

      Rules for each column
      Column Contains Written like Must not be empty Must be unique Repair: trim spaces Repair: convert format Repair: protect formulas

      "Repair" options change values only in the cleaned copy, and only in the columns you tick. Nothing else is touched. "Protect formulas" puts a ' before text that starts with = + - or @, so that Excel shows it instead of running it as a formula.

      The first row is always the one that is kept.

      More settings

      A longer value stops reading with "field too large". It usually means an unclosed quote. Raise it only for files with very long texts. Saved in profiles as max_field_chars.

      How much detail to show

      Counts are always complete. These limits set how many items are listed on the page and in saved reports.

      Combined unique keys

      Use this when two or more columns together must be unique (for example customer and date).

        How to use
        1. Choose: Drop a CSV file or press +.
        2. Look: Check the separator and encoding in the preview.
        3. Columns: Give the columns you care about a type and format.
        4. Check: See the problems with their row and column.
        5. Preview: See which values will change.
        6. Save: Download the clean copy and the report.

        Save your rules as a profile to reuse them here or with the csv-tidy command.

        Local only — nothing leaves this computer

        Quit CSV Tidy?

        This stops CSV Tidy on this computer and removes its temporary copies. Rules and previews that you did not save are cleared. Your original files are not changed.

        Start a new check?

        This clears the loaded files, the rules, and the results on this page. Files you already saved and your original files are not changed.
